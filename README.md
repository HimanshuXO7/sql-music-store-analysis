
# SQL Music Store Analysis

## Project Overview

This project analyzes a Music Store database using SQL queries to answer business-related questions and generate insights from sales and customer data.

## Tools Used

- SQL
- MySQL

## Project Objectives

- Analyze customer purchasing behavior
- Identify top-selling artists and genres
- Determine highest revenue-generating countries
- Find best customers based on spending
- Generate business insights using SQL queries

## Files Included

- music_store_database_Project.sql
- Music Store Analysis-Questions.pdf
- music_store_data.zip

## Skills Demonstrated

- SQL Queries
- Joins
- Aggregate Functions
- Subqueries
- Common Table Expressions (CTEs)
- Data Analysis
- Business Problem Solving
